About

A second route, so that "it routes" is a claim with evidence rather than a single page that happens to be served.

{{.Runtime}}

Three processes run this: css, jobs and app. There is no database process — the database is a FILE in this checkout, at $DATABASE_PATH, and GORM migrates it at boot. The entries page enqueues; the worker records; the app notices the new row and tells every open browser.

The API is described at /openapi.json , served by the same router as these pages.
