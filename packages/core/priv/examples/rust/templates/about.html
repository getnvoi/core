About

A second route, so that "it routes" is a claim with evidence rather than a single page that happens to be served.

actix-web · actix-ws · Apalis · Diesel · SQLite

Three processes run this: css, jobs and app. There is no database process — the database is a FILE in this checkout, at $DATABASE_PATH, and Diesel's embedded migrations run at boot. The entries page enqueues; the worker records; the app notices the new row and tells every open browser.
