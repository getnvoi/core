## Authentication

### `nvoi login`

Log in to a workspace and keep its token as a context

```bash
nvoi login [flags]
```

| flag | | |
| --- | --- | --- |
| `--email` | required | the account's email |
| `--endpoint` |  | the server to log in to, instead of the context's or https://nvoi.to |
| `--password` | required | the account's password |
| `--workspace` |  | the workspace slug the token is for; the account's first when absent |

### `nvoi logout`

Revoke the context's token and forget it

```bash
nvoi logout
```

### `nvoi signup`

Sign up with an email and a password: an account and its workspace, pending approval

```bash
nvoi signup [flags]
```

| flag | | |
| --- | --- | --- |
| `--email` | required | the account's email |
| `--endpoint` |  | the server to sign up on, instead of the context's or https://nvoi.to |
| `--password` | required | the account's password, at least 12 characters |
| `--workspace` | required | the new workspace's name |

### `nvoi whoami`

The account and workspace the token names

```bash
nvoi whoami
```
